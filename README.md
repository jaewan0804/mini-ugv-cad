# MINI-UGV 3D CAD Studio (Rev 4.0)

컴팩트 듀얼 블레이드 자율 예초로봇(UGV) 3D CAD 인터랙티브 뷰어 및 32종 실측 부품 도감 웹 스튜디오입니다.

- **Live Demo (GitHub Pages)**: https://jaewan0804.github.io/mini-ugv-cad/
- **주요 기능**:
  - 3D 조립 / **보닛 62° 힌지 오픈 + 듀얼 배터리 수직 리프팅 교체 시뮬레이션** / 완전 분해 뷰어
  - 완제품 vs 분해 도면 비교 및 32종 단품 실측 데이터시트
  - 간섭·칼날 비충돌 계산(`D = 241.9mm > Ø230mm`) 및 3030 프로파일 재단표
